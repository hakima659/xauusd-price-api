
# XAUUSD Price API

Cloudflare Worker for retrieving the latest XAU/USD spot gold price.

## Endpoint

This Worker fetches the XAU/USD spot price from GoldPrice.dev.

## Technology

- Cloudflare Workers
- JavaScript
- GoldPrice.dev API

## Purpose

This API is used as the price-data layer for the XAUUSD MT5 trading project.
